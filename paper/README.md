# Paper Experiments

This directory contains scripts for generating figures and running experiments for my dialogue topic segmentation paper. Given the disorganization that creeps into large projects, I had an AI assistant clean up and organize the files for easy regeneration. I have verified the data (in results/) and scripts reproduce the figures and tables reported in the paper. 

## Initial Sanity Check

I'm very interested in making it much easier for people to verify publication results. You can replicate this verification by pointing an AI coding assistant at this directory along with the paper PDF. Tools such as Claude Code, Codex, or aider (open-source) can do this. You can use a prompt such as:

## Figure Generation Pipeline

### Entry Points

| Script | Description | Speed |
|--------|-------------|-------|
| `python paper/scripts/density_quality_curves.py` | Full sweep - recomputes all predictions | Slow (~5 min) |
| `python paper/scripts/density_quality_curves.py --exact-f1-only` | Generate exact F1 figure from existing CSVs | Fast |
| `python paper/scripts/regenerate_density_quality_figures.py` | Regenerate W-F1/Coverage figures from existing CSVs | Fast |
| `python paper/scripts/density_quality_diagnostics.py` | Generate diagnostic figures | Medium |
| `python paper/scripts/compute_density_quality_cis.py` | Compute bootstrap CIs and generate CI figures | Slow |

### Data Flow

```
Predictions (recomputed or cached)
         │
         ▼
paper/results/sweep_{dataset}_{method}.csv   ← Sweep data
         │
         ▼
paper/figures/density_quality_*.pdf          ← Generated figures
```

### Sweep CSV Format

Location: `paper/results/sweep_{dataset}_{method}.csv`

| Column | Description |
|--------|-------------|
| `dataset` | Dataset name (dialseg711, superseg) |
| `model` | Method name (neural, texttiling, csm, random) |
| `g` | Minimum gap parameter (default: 2) |
| `step` | Sweep step index |
| `tau` | Threshold value |
| `bor` | Boundary Oversegmentation Ratio (predicted/gold) |
| `wf1` | W-F1 score (many-to-one tolerant matching) |
| `wf1_1to1` | W-F1 score (one-to-one tolerant matching) |
| `exact_f1` | Exact F1 (strict position matching, no tolerance) |
| `coverage` | Segment coverage metric |
| `purity` | Segment purity metric |
| `n_pred_boundaries` | Total predicted boundaries |
| `n_gold_boundaries` | Total gold boundaries |
| `seed` | Random seed (only for random baseline) |

### Figure Outputs

Location: `paper/figures/`

| Figure | Generated By |
|--------|--------------|
| `density_quality_{dataset}.pdf` | `scripts/density_quality_curves.py` |
| `density_quality_{dataset}_regimes.pdf` | `scripts/density_quality_curves.py` |
| `density_quality_{dataset}_ci_regimes_v2.pdf` | `scripts/regenerate_density_quality_figures.py` |
| `density_quality_exact_f1.pdf` | `scripts/density_quality_curves.py --exact-f1-only` |

| `per_dialogue_bor_{dataset}.pdf` | `scripts/density_quality_diagnostics.py` |

## Dependencies

### Script Dependencies

| Script | Reads from CSVs | Recomputes Predictions |
|--------|-----------------|----------------------|
| `scripts/density_quality_curves.py` | Yes (with `--exact-f1-only`) | Yes (default) |
| `scripts/regenerate_density_quality_figures.py` | Yes | No |
| `scripts/density_quality_diagnostics.py` | Yes | Yes (for per-dialogue analysis) |
| `scripts/compute_density_quality_cis.py` | No | Yes |

### Canonical Source Files

- **Evaluation metrics**: `episodic/topics/evaluation.py`
  - `compute_windowed_metrics()` - W-F1 computation
  - `compute_exact_f1()` - Strict position matching F1
  - `compute_purity_coverage()` - Segment-level metrics

- **Data structures and scoring**: `paper/scripts/density_quality_curves.py`
  - `DialogueData` - Dialogue container dataclass
  - `load_dataset()` - Load dialogues from JSON
  - `get_neural_scores()`, `get_texttiling_scores()`, etc. - Scoring functions

## Method Colors

All figures use consistent colors (Okabe-Ito colorblind-safe palette):

| Method | Color | Hex |
|--------|-------|-----|
| Neural (Proposed) | Blue | `#0072B2` |
| TextTiling | Orange | `#E69F00` |
| CSM (NSP) | Green | `#009E73` |
| Random | Pink | `#CC79A7` |

Regime shading:
- BOR < 1 (undersegmentation): Blue-ish (`#4393c3`)
- BOR > 1 (oversegmentation): Red-ish (`#d6604d`)
